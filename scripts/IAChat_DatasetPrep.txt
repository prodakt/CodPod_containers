JAk bmądrze podzielić cały zestaw, żeby analizy były wiarygodne i żebym nic nie poduplikował?

Aby analiza naukowa była w pełni wiarygodna i wolna od wycieku danych (data leakage), najbezpieczniejszym podejściem jest najpierw usunięcie wszystkich duplikatów między zbiorami, a następnie wykonanie podziału na poziomie unikalnych identyfikatorów próbek, zanim trafią one do poszczególnych etapów modelowania.
W Twoim opisie kryje się kilka pułapek metodologicznych (m.in. wspólne elementy w grupie ex oraz mieszanie zbiorów między etapami), które mogłyby sztucznie zawyżyć wyniki lub zafałszować wnioski w publikacji naukowej.

Krok 1: Czyszczenie i deduplikacja (Zanim zrobisz jakikolwiek podział)

Z opisu wynika, że nc i pc są rozłączne, ale ex zawiera kilka tysięcy elementów wspólnych z nc oraz kilka tysięcy z pc.
1. Zidentyfikuj części wspólne: Wyciągnij ze zbioru ex wszystkie próbki, które występują w nc lub pc.
2. Usuń duplikaty z ex: Skoro już wiesz, że część próbek w ex tak naprawdę należy do nc lub pc, nie możesz ich traktować jako nieznanych próbek do klasyfikacji. Pozostaw w ex wyłącznie unikalne próbki, których nie ma ani w nc, ani w pc.
	• Wskazówka: Te wspólne próbki (skoro już je usunąłeś, jak wspomniałeś) mogą Ci posłużyć jako dodatkowy, niezależny zbiór walidacyjny (tzw. gold standard) do sprawdzenia, jak model radzi sobie z danymi pochodzącymi ze źródła ex, ale o znanej etykiecie.

Krok 2: Główny podział na dwa poziomy analiz (50% / 50%)

Chcesz podzielić cały zestaw na pół, aby dwa poziomy analiz były od siebie całkowicie niezależne. To bardzo dobra praktyka w badaniach naukowych (zapobiega tzw. p-hackingowi i przeuczeniu hipotez).
• Zbiór nc (ok. 30 tys.) \(\rightarrow \) podziel losowo (stratyfikowanie, jeśli masz podklasy) na Połowa A (15 tys.) i Połowa B (15 tys.).
• Zbiór pc (ok. 30 tys.) \(\rightarrow \) podziel losowo na Połowa A (15 tys.) i Połowa B (15 tys.).
• Zbiór ex (po deduplikacji, ok. 50 tys.) \(\rightarrow \) nie musisz dzielić go na pół, ponieważ w Poziomie 1 w ogóle go nie używasz (tam testujesz tylko metodę na znanych klasach nc i pc). Cały oczyszczony zbiór ex zostaw na Poziom 2.
Uwaga: Zapisz na dysku listy ID próbek należących do Połowy A i Połowy B. Nigdy nie mieszaj ich ze sobą.

Krok 3: Realizacja Poziomu 1 (Walidacja metody na Połowie A)

W tym etapie sprawdzasz, czy Twój algorytm w ogóle potrafi odróżnić nc od pc.
1. Bierzesz tylko Połowę A (nc_A + pc_A, łącznie ok. 30 tys. próbek).
2. Dzielisz ją w proporcji 80% Train / 20% Test (z zachowaniem proporcji klas nc i pc, czyli stratify=y).
	• Uwaga do Twojego opisu: Napisałeś „dzielę to na 20/80”. Standardem naukowym jest 80% na trening i 20% na test (większy zbiór uczy model, mniejszy ocenia jakość). Jeśli zrobisz odwrotnie (20% trening), model może być niedouczony, chyba że masz ku temu konkretny powód (np. symulacja małej próby).
3. Trenujesz model na 80%, oceniasz metryki (ROC-AUC, F1-score, Precision/Recall) na 20%.

Krok 4: Realizacja Poziomu 2 (Właściwa klasyfikacja na Połowie B + ex)

Tutaj pojawia się najważniejsza kwestia metodologiczna: nie możesz trenować modelu na zbiorze ex, jeśli nie znasz jego prawdziwych etykiet (chyba że stosujesz semi-supervised learning, ale z opisu wynika, że chcesz po prostu sklasyfikować ex jako nc lub pc).
1. Bierzesz Połowę B (nc_B + pc_B, ok. 30 tys. próbek) – to są Twoje dane z pewnymi etykietami.
2. Dzielisz Połowę B na 80% Train / 20% Test:
	• 80% Połowy B: Służy do ostatecznego wytrenowania modelu (już po dobraniu hiperparametrów w Poziomie 1).
	• 20% Połowy B: Służy jako ostateczny, niezależny zbiór kontrolny (hold-out test set), żebyś mógł w pracy naukowej zaraportować, jaką skuteczność miał finalny model przed wypuszczeniem go na nieznane dane.
3. Zbiór ex (cały oczyszczony): Traktujesz go jako zbiór inferencyjny (predykcyjny), a nie treningowy czy testowy. Przepuszczasz go przez model wytrenowany na 80% Połowy B i przypisujesz mu etykiety nc lub pc (wraz z prawdopodobieństwem predykcji).

Dlaczego taki podział obroni się przed recenzentami?

• Brak wycieku danych (Data Leakage): Żadna próbka z Poziomu 1 nie bierze udziału w Poziomie 2. Żadna próbka z ex nie jest kopią próbki z nc lub pc.
• Wiarygodność statystyczna: Zarówno w Poziomie 1, jak i w Poziomie 2 zachowujesz równe proporcje klas (nc i pc), co eliminuje problem niezbalansowania klas (class imbalance).
• Kontrola jakości: Posiadanie 20% zbioru testowego w Poziomie 2 daje Ci twardy dowód na to, że finalny model nie przeuczył się na 80% Połowy B przed dokonaniem predykcji na ex.

	• Ważne: Zbiór ex po tym kroku zawiera wyłącznie nowe, niezaadnotowane transkrypty (klasy u, i, x, o z GffCompare). To jest Twój czysty zbiór do odkryć (discovery set).
2. Wydzielenie lnc z nc.fasta:
	• Z pliku nc.fasta odfiltruj znane lncRNA (np. po biotypie lncRNA / długości > 200 nt i braku krótkich ncRNA jak miRNA, snoRNA, tRNA). Masz teraz trzy czyste pule referencyjne:
		• cds (klasa negatywna: kodujące białka)
		• lnc (klasa pozytywna: długie niekodujące)
		• snc / nc_other (pozostałe niekodujące – warto je zachować lub świadomie odrzucić w zależności od tego, czy filtrujesz długość >200 nt na wejściu; standardowo w lncRNA pipeline'ach odrzuca się transkrypty <200 nt na samym starcie).
3. Kluczowa pułapka w transkryptomice – podział na poziomie GENU, nie transkryptu:
	• Jeśli z jednego genu masz 5 izoform i 3 trafią do Train, a 2 do Test, model nauczy się sekwencji tego genu i zawyży wyniki (szczególnie u myszy, gdzie jest dużo izoform). Grupuj po gene_id (lub klastrach CD-HIT-EST na 80–90% podobieństwa) przed podziałem na Train i Test.

2. Ile próbek wystarczy? (Zamiast sztywnych procentów: reguła progowa)

Twoja intuicja ze stałą liczbą próbek (np. 1500 lncRNA) jest bardzo słuszna. W bioinformatyce algorytmy oparte na cechach sekwencyjnych i strukturalnych (XGBoost, Random Forest, LightGBM – zakładam, że używasz czegoś takiego w etapie ml łącząc wyniki CPC2, CPAT, PLEK, FEELnc itp. + długość, liczba eksonów, polyA) wysycają się dość szybko.

Minimalne i optymalne liczby próbek (dla organizmów modelowych i niemodelowych):

• Minimum absolutne (organizmy niemodelowe): 500–800 unikalnych genów lnc (wtedy dzielisz 80/20: ~400–640 Train, ~100–160 Test). Przy mniejszej liczbie lepiej użyć 5-krotnej walidacji krzyżowej (5-fold CV) zamiast sztywnego podziału 80/20, żeby nie tracić danych.
• Złoty standard / punkt wysycenia (mysz, człowiek, ryba): 1 500 – 2 500 unikalnych genów lnc na etap. Powyżej ~3 000 próbek przyrost jakości na cechach tabelarycznych (wyniki z cp + długość + eksony) jest już marginalny (rzędu 0.1–0.3% AUC), a zyskujesz tylko na czasie obliczeń.
• Balans klas (lnc vs cds): W treningu najlepiej utrzymywać proporcję 1:1 lub 1:2 (np. 2000 lnc i 2000–4000 cds). Natomiast w zbiorze testowym (20%) możesz zachować proporcję naturalną lub również 1:1 (wtedy wyraźnie piszesz w pracy, że ewaluacja była na zbalansowanym zbiorze testowym).

3. Uniwersalny schemat podziału (Schemat Hybrydowy: Stały Budżet Próbek)

Ponieważ w etapie ml używasz wyników z etapu cp jako cech wejściowych (meta-cech), nie możesz trenować cp i ml na tych samych danych (bo narzędzia z cp będą miały sztucznie zawyżoną skuteczność na własnym zbiorze treningowym, co oszuka klasyfikator ml!).
Rozwiązaniem jest podział na dwa niezależne bloki (Blok CP i Blok ML) z limitem próbek (tzw. cap na poziomie np. 2 500 próbek na blok).

Dlaczego ten schemat zadziała idealnie w Twojej pracy?

1. Co robisz z nadmiarem danych u myszy?
	• Jeśli mysz ma 15 000 znanych lnc, a Ty weźmiesz 2 500 do cp i 2 500 do ml, zostaje Ci 10 000 nieużytych znanych lnc (oraz odpowiednia pula cds). Możesz ich użyć jako trzeciego, niezależnego zbioru walidacyjnego (External Benchmark), żeby pokazać recenzentom skuteczność całego dwuetapowego pipeline'u na ogromnej próbie.
2. Co jeśli w organizmie niemodelowym masz za mało lnc na podział 50/50 między cp a ml (np. w bazie jest tylko 300 znanych lnc)?
	• Wtedy używasz tzw. Out-of-Fold (OOF) predictions: nie dzielisz danych na Blok 1 i Blok 2. Robisz jedną wspólną pulę (np. 300 lnc + 600 cds) i dzielisz ją w 5-krotnej walidacji krzyżowej (5-fold CV). Narzędzia cp trenowane na 4/5 danych robią predykcję na pozostałej 1/5. Dzięki temu każdy transkrypt dostaje uczciwą predykcję cp (bez wycieku danych), na której potem uczy się model ml.
	• Uwaga: Jeśli w etapie cp używasz wyłącznie gotowych, pretrenowanych modeli (np. standardowego CPC2, LncFinder bez własnego retreningu), to nie potrzebujesz Bloku 1 do treningu cp – całą dostępną pulę lnc i cds (np. do limitu 3 000 na klasę) przeznaczasz od razu na Blok 2 (ml 80% Train / 20% Test).
Daj znać, czy w etapie cp:
• Trenujesz narzędzia od zera na swoich danych (np. budujesz własne modele HEXAMER/logit dla CPAT/PLEK dla każdego gatunku), czy używasz gotowych, pretrenowanych modeli?
• Używasz na wejściu pliku GTF (bo wspomniałeś o liczbie eksonów), czy tylko plików FASTA?

library(Biostrings)

prepare_data <- function(cds_file,
                         nc_file,
                         prefix,
                         seed          = 123,
                         stage_prop    = 0.5,
                         stage_method  = "exact",  # "exact", "sample", "rep"
                         tt_prop       = 0.8,
                         tt_method     = "exact",  # "exact", "sample", "rep"
                         balance_train = FALSE) {

  set.seed(seed)

  # 1. Wczytanie FASTA i zmiana nazw
  cds <- readDNAStringSet(cds_file)
  nc  <- readDNAStringSet(nc_file)

  cds_new <- paste(prefix, "cds", sprintf("%07d", seq_along(cds)), sep = "_")
  nc_new  <- paste(prefix, "nc",  sprintf("%07d", seq_along(nc)),  sep = "_")

  df <- data.frame(
    ID       = c(cds_new, nc_new),
    old_name = c(names(cds), names(nc)),
    class    = c(rep("cds", length(cds)), rep("nc", length(nc))),
    stringsAsFactors = FALSE
  )

  names(cds) <- cds_new
  names(nc)  <- nc_new
  all_seqs   <- c(cds, nc)

  # Pomocniczy podział
  split_vec <- function(n, labels, prop, method) {
    if (method == "rep") {
      rep(labels, length.out = n)
    } else if (method == "sample") {
      sample(labels, size = n, replace = TRUE, prob = c(prop, 1 - prop))
    } else {
      n1 <- round(n * prop)
      sample(c(rep(labels[1], n1), rep(labels[2], n - n1)))
    }
  }

  # 2. Podział 50/50 (ml vs cp) osobno dla cds i nc
  df$stage <- ave(df$class, df$class, FUN = function(x) {
    split_vec(length(x), c("ml", "cp"), stage_prop, stage_method)
  })

  # 3. Podział 80/20 (train vs test) wewnątrz każdej grupy (class + stage)
  grp <- paste(df$class, df$stage, sep = "_")
  df$tt_set <- ave(grp, grp, FUN = function(x) {
    split_vec(length(x), c("train", "test"), tt_prop, tt_method)
  })

  df$cohort <- paste(df$class, df$stage, df$tt_set, sep = "_")
  df$keep   <- TRUE

  # 4. Opcjonalne wyrównanie klas 1:1 w zbiorach train
  if (balance_train) {
    for (st in c("ml", "cp")) {
      idx_cds <- which(df$stage == st & df$tt_set == "train" & df$class == "cds")
      idx_nc  <- which(df$stage == st & df$tt_set == "train" & df$class == "nc")
      n_min   <- min(length(idx_cds), length(idx_nc))

      if (length(idx_cds) > n_min) {
        drop <- idx_cds[sample.int(length(idx_cds), length(idx_cds) - n_min)]
        df$keep[drop] <- FALSE
      }
      if (length(idx_nc) > n_min) {
        drop <- idx_nc[sample.int(length(idx_nc), length(idx_nc) - n_min)]
        df$keep[drop] <- FALSE
      }
    }
  }

  return(list(seqs = all_seqs, legend = df))
}

Co trzeba poprawić w obecnym kodzie? (Diagnoza)

1. Błąd w zmiennej na dole skryptu: W funkcji używasz kolumny df$keep, a w sekcji testującej odwołujesz się do nieistniejącej kolumny df$exported (zwróci NULL i pustą ramkę danych).
2. Brak wydzielenia lncRNA z ncrna.fa.gz: Plik Ensembl ncrna.fa.gz zawiera mnóstwo krótkich RNA (miRNA, snoRNA, snRNA, rRNA, tRNA) oraz lncRNA. Nagłówki Ensembl mają format np. >ENSMUST... ncrna ... transcript_biotype:lncRNA .... Jeśli nie wyciągniesz biotypu lncRNA przed podziałem 50/50, nie masz gwarancji, ile lncRNA trafi do etapu ml.
3. Brak obsługi pliku ex (merged_transcriptome.fasta) i deduplikacji po sekwencji: W Ensembl (a szczególnie w StringTie) różne rekordy potrafią mieć identyczną sekwencję nukleotydową, mimo innych ID. Samo sprawdzanie intersect(old_name) nie wykryje identycznych sekwencji między ex a cds/nc. Trzeba deduplikować po samej sekwencji (as.character(seqs)).
4. Filtrowanie długości (<200 nt): Definicyjnie lncRNA mają \(\ge 200\) nt. Jeśli nie odfiltrujesz krótkich sekwencji na samym początku, zbiór nc będzie sztucznie zdominowany przez krótkie ncRNA, a model nauczy się trywialnej reguły „krótkie = niekodujące”.
5. Brak limitu maksymalnej liczby próbek (max_per_class): Przy myszy masz dziesiątki tysięcy transkryptów, ale przy organizmach niemodelowych będzie ich znacznie mniej. Dodanie parametru limitującego (np. max 2500 próbek na klasę w danym etapie) pozwoli używać dokładnie tego samego skryptu dla myszy i dla gatunków niemodelowych.

Poprawiony, uniwersalny skrypt w R (prepare_data)

Poniższy kod rozwiązuje wszystkie powyższe problemy:
• Odrzuca sekwencje < 200 nt i deduplikuje po sekwencji.
• Wyciąga lnc z nagłówków Ensembl ncrna.fa.gz (poprzez transcript_biotype:lncRNA), tworząc 3 klasy: cds, lnc, nc_other.
• Robi stratyfikowany podział na cp i ml (gwarantując równy podział lnc).
• Wczytuje ex (merged_transcriptome.fasta) i usuwa z niego wszelkie sekwencje identyczne z cds lub nc (zarówno te użyte, jak i odrzucone przy balansowaniu!).
• Pozwala ustawić limit próbek (max_n_stage) dla bogatych genomów (np. mysz).
r
library(Biostrings)

prepare_data <- function(cds_file,
                         nc_file,
                         ex_file       = NULL,
                         prefix        = "Mus",
                         min_len       = 200,
                         seed          = 123,
                         stage_prop    = 0.5,    # proporcja ml vs cp
                         tt_prop       = 0.8,    # proporcja train vs test
                         max_n_stage   = Inf,    # np. 2500 dla myszy, Inf dla niemodelowych
                         balance_train = TRUE,
                         ml_neg_mode   = "cds_only") { # "cds_only" lub "cds_and_nc_other"

  set.seed(seed)

  # --- 1. WCZYTANIE I FILTROWANIE DŁUGOŚCI (>= 200 nt) ---
  cds <- readDNAStringSet(cds_file)
  nc  <- readDNAStringSet(nc_file)

  cds <- cds[width(cds) >= min_len]
  nc  <- nc[width(nc) >= min_len]

  # --- 2. WYDZIELENIE BIOTYPU lncRNA Z PLIKU nc.fasta ---
  # W Ensembl nagłówki zawierają "transcript_biotype:lncRNA" (lub "gene_biotype:lncRNA")
  is_lnc <- grepl("transcript_biotype:lncRNA|gene_biotype:lncRNA", names(nc), ignore.case = TRUE)
  nc_subclasses <- ifelse(is_lnc, "lnc", "nc_other")

  df_ref <- data.frame(
    old_name  = c(names(cds), names(nc)),
    class     = c(rep("cds", length(cds)), nc_subclasses),
    seq_char  = c(as.character(cds), as.character(nc)),
    stringsAsFactors = FALSE
  )

  # --- 3. DEDUPLIKACJA PO SEKWENCJI (ZERO WYCIEKÓW MIĘDZY ZBIORAMI) ---
  # Jeśli ta sama sekwencja występuje w cds i nc, usuwamy duplikat (priorytet ma cds)
  dup_mask <- duplicated(df_ref$seq_char)
  if (any(dup_mask)) {
    message(sprintf("Usunięto %d duplikatów sekwencji wewnątrz referencji (cds/nc).", sum(dup_mask)))
    df_ref <- df_ref[!dup_mask, ]
  }

  # Nadanie nowych, czystych ID
  df_ref$ID <- paste(prefix, df_ref$class, sprintf("%07d", seq_len(nrow(df_ref))), sep = "_")

  # --- 4. STRATYFIKOWANY PODZIAŁ NA ETAPY: ml vs cp ---
  split_exact <- function(n, labels, prop) {
    n1 <- round(n * prop)
    sample(c(rep(labels[1], n1), rep(labels[2], n - n1)))
  }

  df_ref$stage <- ave(df_ref$class, df_ref$class, FUN = function(x) {
    split_exact(length(x), c("ml", "cp"), stage_prop)
  })

  # --- 5. PODZIAŁ TRAIN / TEST (80/20) WEWNĄTRZ (class + stage) ---
  grp <- paste(df_ref$class, df_ref$stage, sep = "_")
  df_ref$tt_set <- ave(grp, grp, FUN = function(x) {
    split_exact(length(x), c("train", "test"), tt_prop)
  })

  df_ref$cohort <- paste(df_ref$class, df_ref$stage, df_ref$tt_set, sep = "_")
  df_ref$keep   <- TRUE

  # --- 6. DEFINICJA RÓL W ETAPACH I OPCJONALNY LIMIT / BALANSOWANIE ---
  # W etapie 'cp': klasa poz = (lnc + nc_other), klasa neg = cds
  # W etapie 'ml': klasa poz = lnc, klasa neg = cds (lub cds + nc_other)
  df_ref$role <- NA_character_
  df_ref$role[df_ref$stage == "cp" & df_ref$class %in% c("lnc", "nc_other")] <- "pos"
  df_ref$role[df_ref$stage == "cp" & df_ref$class == "cds"]                    <- "neg"

  df_ref$role[df_ref$stage == "ml" & df_ref$class == "lnc"]                    <- "pos"
  if (ml_neg_mode == "cds_only") {
    df_ref$role[df_ref$stage == "ml" & df_ref$class == "cds"]                  <- "neg"
    df_ref$keep[df_ref$stage == "ml" & df_ref$class == "nc_other"]             <- FALSE
  } else {
    df_ref$role[df_ref$stage == "ml" & df_ref$class %in% c("cds", "nc_other")] <- "neg"
  }

  # Balansowanie 1:1 oraz nakładanie limitu max_n_stage w zbiorach TRAIN
  if (balance_train || is.finite(max_n_stage)) {
    for (st in c("cp", "ml")) {
      # Limit na cały etap (80% train, 20% test)
      max_tr <- floor(max_n_stage * tt_prop)
      max_te <- floor(max_n_stage * (1 - tt_prop))

      for (tt in c("train", "test")) {
        lim <- if (tt == "train") max_tr else max_te
        idx_pos <- which(df_ref$stage == st & df_ref$tt_set == tt & df_ref$role == "pos" & df_ref$keep)
        idx_neg <- which(df_ref$stage == st & df_ref$tt_set == tt & df_ref$role == "neg" & df_ref$keep)

        if (tt == "train" && balance_train) {
          target_n <- min(length(idx_pos), length(idx_neg), lim)
        } else {
          target_n <- min(max(length(idx_pos), length(idx_neg)), lim)
        }

        if (length(idx_pos) > target_n) {
          drop_pos <- idx_pos[sample.int(length(idx_pos), length(idx_pos) - target_n)]
          df_ref$keep[drop_pos] <- FALSE
        }
        if (length(idx_neg) > target_n) {
          drop_neg <- idx_neg[sample.int(length(idx_neg), length(idx_neg) - target_n)]
          df_ref$keep[drop_neg] <- FALSE
        }
      }
    }
  }

  # --- 7. OBSŁUGA ZBIORU EKSPERYMENTALNEGO (ex - StringTie) ---
  df_ex <- NULL
  if (!is.null(ex_file)) {
    ex <- readDNAStringSet(ex_file)
    ex <- ex[width(ex) >= min_len]

    df_ex <- data.frame(
      old_name = names(ex),
      class    = "ex",
      seq_char = as.character(ex),
      stringsAsFactors = FALSE
    )

    # Deduplikacja wewnątrz samego ex
    df_ex <- df_ex[!duplicated(df_ex$seq_char), ]

    # Usunięcie z ex WSZYSTKICH sekwencji obecnych w referencji (cds/nc)
    in_ref <- df_ex$seq_char %in% df_ref$seq_char
    message(sprintf("Zbiór ex: usunięto %d transkryptów identycznych z referencją (cds/nc).", sum(in_ref)))
    df_ex <- df_ex[!in_ref, ]

    df_ex$ID     <- paste(prefix, "ex", sprintf("%07d", seq_len(nrow(df_ex))), sep = "_")
    df_ex$stage  <- "inference"
    df_ex$tt_set <- "predict"
    df_ex$cohort <- "ex_inference"
    df_ex$keep   <- TRUE
    df_ex$role   <- "unknown"
  }

  # --- 8. ZŁOŻENIE FINALNYCH OBIEKTÓW ---
  df_all <- rbind(df_ref, df_ex)
  all_seqs <- DNAStringSet(df_all$seq_char)
  names(all_seqs) <- df_all$ID

  # Usuwamy surową sekwencję z ramki danych, żeby tabela była lekka
  df_all$seq_char <- NULL

  return(list(seqs = all_seqs, legend = df_all))
}

library(Biostrings)

prepare_data <- function(cds_file,
                         nc_file,
                         lnc_file      = NULL,          # Opcjonalny osobny plik tylko z lncRNA
                         ex_file       = NULL,          # Opcjonalny plik StringTie (ex)
                         prefix        = "Species",
                         extract_lnc   = TRUE,          # Ścieżka A (TRUE) vs Ścieżka B (FALSE)
                         lnc_pattern   = "lncRNA|lnc_rna|long_non_coding", # Uniwersalny regex
                         dedup_mode    = "exact_seq",   # "none", "exact_seq", "header_id"
                         seed          = 123,
                         stage_prop    = 0.5,           # Proporcja podziału na etapy (ml vs cp)
                         stage_method  = "exact",       # "exact", "sample", "rep"
                         tt_prop       = 0.8,           # Proporcja train vs test
                         tt_method     = "exact",       # "exact", "sample", "rep"
                         max_n_stage   = Inf,           # Limit próbek na klasę w etapie (np. 2500 lub Inf)
                         balance_train = FALSE,         # Wyrównanie 1:1 w zbiorach train
                         ml_neg_mode   = "cds_only") {  # W Ścieżce A: "cds_only" lub "cds_and_nc_other"

  set.seed(seed)

  # --- 1. WCZYTANIE PLIKÓW WEJŚCIOWYCH ---
  cds <- readDNAStringSet(cds_file)
  nc  <- readDNAStringSet(nc_file)
  
  df_cds <- data.frame(old_name = names(cds), raw_group = "cds", seq_char = as.character(cds), stringsAsFactors = FALSE)
  df_nc  <- data.frame(old_name = names(nc),  raw_group = "nc",  seq_char = as.character(nc),  stringsAsFactors = FALSE)
  
  df_lnc <- NULL
  if (!is.null(lnc_file)) {
    lnc <- readDNAStringSet(lnc_file)
    df_lnc <- data.frame(old_name = names(lnc), raw_group = "lnc_ext", seq_char = as.character(lnc), stringsAsFactors = FALSE)
  }

  df_ex <- NULL
  if (!is.null(ex_file)) {
    ex <- readDNAStringSet(ex_file)
    df_ex <- data.frame(old_name = names(ex), raw_group = "ex", seq_char = as.character(ex), stringsAsFactors = FALSE)
  }

  # Łączymy w ustalonej kolejności priorytetów (cds -> lnc_ext -> nc -> ex)
  df_all <- rbind(df_cds, df_lnc, df_nc, df_ex)

  # --- 2. IDENTYFIKACJA POTENCJALNYCH lncRNA (RAPORT DIAGNOSTYCZNY) ---
  in_lnc_ext <- df_all$raw_group == "lnc_ext"
  in_nc_match <- df_all$raw_group == "nc" & grepl(lnc_pattern, df_all$old_name, ignore.case = TRUE)
  is_lnc_candidate <- in_lnc_ext | in_nc_match

  message(sprintf("[INFO] Znaleziono łącznie %d rekordów pasujących do lncRNA (przed deduplikacją).", sum(is_lnc_candidate)))

  # Przypisanie klas zgodnie z wybraną ścieżką (A vs B)
  df_all$class <- df_all$raw_group
  if (extract_lnc) {
    # ŚCIEŻKA A: Wyodrębniamy 'lnc', reszta z pliku nc staje się 'nc_other'
    df_all$class[is_lnc_candidate] <- "lnc"
    df_all$class[df_all$raw_group == "nc" & !is_lnc_candidate] <- "nc_other"
    message("[ŚCIEŻKA A] Aktywna: wyodrębniono klasę 'lnc' oraz 'nc_other'.")
  } else {
    # ŚCIEŻKA B: Nie wyodrębniamy lncRNA – wszystko z nc (i ewentualnego lnc_file) to jedna klasa 'nc'
    df_all$class[df_all$raw_group %in% c("nc", "lnc_ext")] <- "nc"
    message("[ŚCIEŻKA B] Aktywna: brak podziału na podklasy – użyto pełnej klasy 'nc'.")
  }

  # --- 3. OPCJONALNA DEDUPLIKACJA ---
  if (dedup_mode != "none") {
    n_before <- nrow(df_all)
    if (dedup_mode == "exact_seq") {
      dup_mask <- duplicated(df_all$seq_char)
    } else if (dedup_mode == "header_id") {
      # Wyciąga pierwsze słowo z nagłówka FASTA (przed pierwszą spacją/tabulatorem)
      clean_ids <- sub("\\s+.*$", "", df_all$old_name)
      dup_mask <- duplicated(clean_ids)
    } else {
      stop("Nieznany dedup_mode. Wybierz: 'none', 'exact_seq' lub 'header_id'.")
    }
    df_all <- df_all[!dup_mask, ]
    message(sprintf("[DEDUP: %s] Usunięto %d duplikatów (zostało %d rekordów).", dedup_mode, sum(dup_mask), nrow(df_all)))
  }

  # Nadanie unikalnych ID po czyszczeniu
  df_all$ID <- ave(df_all$class, df_all$class, FUN = function(x) {
    paste(prefix, x[1], sprintf("%07d", seq_along(x)), sep = "_")
  })

  # Rozdzielenie na referencję (cds/nc/lnc) i zbiór eksperymentalny (ex)
  df_ref <- df_all[df_all$class != "ex", ]
  df_exp <- df_all[df_all$class == "ex", ]

  # --- 4. FUNKCJA POMOCNICZA DO PODZIAŁÓW ---
  split_vec <- function(n, labels, prop, method) {
    if (n == 0) return(character(0))
    if (method == "rep") {
      rep(labels, length.out = n)
    } else if (method == "sample") {
      sample(labels, size = n, replace = TRUE, prob = c(prop, 1 - prop))
    } else {
      n1 <- round(n * prop)
      sample(c(rep(labels[1], n1), rep(labels[2], n - n1)))
    }
  }

  # Podział 50/50 (ml vs cp) stratyfikowany po 'class'
  df_ref$stage <- ave(df_ref$class, df_ref$class, FUN = function(x) {
    split_vec(length(x), c("ml", "cp"), stage_prop, stage_method)
  })

  # Podział 80/20 (train vs test) stratyfikowany po 'class' + 'stage'
  grp <- paste(df_ref$class, df_ref$stage, sep = "_")
  df_ref$tt_set <- ave(grp, grp, FUN = function(x) {
    split_vec(length(x), c("train", "test"), tt_prop, tt_method)
  })

  df_ref$cohort <- paste(df_ref$class, df_ref$stage, df_ref$tt_set, sep = "_")
  df_ref$keep   <- TRUE

  # --- 5. PRZYPISANIE RÓL (POS / NEG) W ZALEŻNOŚCI OD ŚCIEŻKI ---
  df_ref$role <- NA_character_
  if (extract_lnc) {
    # ŚCIEŻKA A:
    # W 'cp': pos = lnc + nc_other, neg = cds
    df_ref$role[df_ref$stage == "cp" & df_ref$class %in% c("lnc", "nc_other")] <- "pos"
    df_ref$role[df_ref$stage == "cp" & df_ref$class == "cds"]                    <- "neg"
    
    # W 'ml': pos = lnc, neg = cds (lub cds + nc_other)
    df_ref$role[df_ref$stage == "ml" & df_ref$class == "lnc"]                    <- "pos"
    if (ml_neg_mode == "cds_only") {
      df_ref$role[df_ref$stage == "ml" & df_ref$class == "cds"]                  <- "neg"
      df_ref$keep[df_ref$stage == "ml" & df_ref$class == "nc_other"]             <- FALSE
    } else {
      df_ref$role[df_ref$stage == "ml" & df_ref$class %in% c("cds", "nc_other")] <- "neg"
    }
  } else {
    # ŚCIEŻKA B (brak wydzielonego lnc):
    # Zarówno w 'cp', jak i w 'ml': pos = nc, neg = cds
    df_ref$role[df_ref$class == "nc"]  <- "pos"
    df_ref$role[df_ref$class == "cds"] <- "neg"
  }

  # --- 6. OPCJONALNY LIMIT LICZEBNOŚCI ORAZ BALANSOWANIE 1:1 ---
  if (balance_train || is.finite(max_n_stage)) {
    for (st in c("cp", "ml")) {
      max_tr <- floor(max_n_stage * tt_prop)
      max_te <- floor(max_n_stage * (1 - tt_prop))

      for (tt in c("train", "test")) {
        lim <- if (tt == "train") max_tr else max_te
        idx_pos <- which(df_ref$stage == st & df_ref$tt_set == tt & df_ref$role == "pos" & df_ref$keep)
        idx_neg <- which(df_ref$stage == st & df_ref$tt_set == tt & df_ref$role == "neg" & df_ref$keep)

        if (tt == "train" && balance_train) {
          target_n <- min(length(idx_pos), length(idx_neg), lim)
        } else {
          target_n <- min(max(length(idx_pos), length(idx_neg)), lim)
        }

        if (length(idx_pos) > target_n) {
          df_ref$keep[idx_pos[sample.int(length(idx_pos), length(idx_pos) - target_n)]] <- FALSE
        }
        if (length(idx_neg) > target_n) {
          df_ref$keep[idx_neg[sample.int(length(idx_neg), length(idx_neg) - target_n)]] <- FALSE
        }
      }
    }
  }

  # --- 7. DOPISANIE ZBIORU EX (JEŚLI PODANO) ---
  if (nrow(df_exp) > 0) {
    df_exp$stage  <- "inference"
    df_exp$tt_set <- "predict"
    df_exp$cohort <- "ex_inference"
    df_exp$keep   <- TRUE
    df_exp$role   <- "unknown"
    df_final <- rbind(df_ref, df_exp)
  } else {
    df_final <- df_ref
  }

  # Złożenie obiektu DNAStringSet
  all_seqs <- DNAStringSet(df_final$seq_char)
  names(all_seqs) <- df_final$ID
  df_final$seq_char <- NULL

  return(list(seqs = all_seqs, legend = df_final))
}

Bardzo słuszne podejście. Rozdzielenie tego na dwa osobne kroki w R:
1. inspect_data() (Szybka inspekcja i raport liczebności) – sprawdzasz ile dokładnie masz sekwencji przed i po deduplikacji, ile z nich pasuje do wzorca lncRNA i na tej podstawie podejmujesz świadomą decyzję (Ścieżka A vs Ścieżka B oraz ewentualny limit próbek).
2. prepare_data() (Właściwe dzielenie) – uruchamiasz dopiero wtedy, gdy znasz już dokładne liczby.

Jak do liczebności próbek ma się teoria statystyki i uczenia maszynowego?

W statystyce i uczeniu maszynowym problem wielkości próby przy klasyfikacji (szczególnie w bioinformatyce, gdzie pracujesz na wektorze kilkunastu/kilkudziesięciu cech: wyniki narzędzi cp + długość, liczba eksonów, obecność ogona polyA, skład nukleotydowy) opiera się na kilku twardych prawach:
1. Reguła EPV (Events Per Variable – reguła Peduzziego / Harrella):
	• Klasyczna statystyka mówi, że na 1 cechę (predyktor) w modelu powinno przypadać minimum 10–20 obserwacji z klasy mniejszościowej (u Ciebie: lncRNA w zbiorze Train).
	• Przykład: Jeśli w etapie ml masz 15 cech wejściowych (np. wyniki z 5 narzędzi CP + 10 cech strukturalnych transkryptu), to absolutne minimum statystyczne dla zbioru treningowego wynosi \(15 \times 20 = 300\) próbek lncRNA (czyli ok. 375 lncRNA łącznie w etapie ml przed podziałem 80/20). Poniżej tej granicy rośnie wariancja estymatorów i model zaczyna się przeuczać (overfitting).
2. Krzywa uczenia i prawo potęgowe (Power Law of Learning Curves):
	• Błąd generalizacji modelu spada wykładniczo tylko na początku (między 100 a ~1500 próbek), po czym wchodzi w tzw. plateau (wypłaszczenie).
	• Dla modeli drzewiastych (Random Forest, XGBoost, LightGBM) operujących na danych tabelarycznych (cechy z cp + cechy transkryptu), po przekroczeniu 1 500 – 2 500 próbek na klasę w zbiorze treningowym krzywa uczenia jest już niemal płaska. Dokładanie kolejnych 20 000 transkryptów myszy nie poprawia już zdolności predykcyjnych (AUC/F1), a jedynie wydłuża obliczenia i obciąża pamięć.
3. Precyzja oszacowania metryk w zbiorze Testowym (Przedziały ufności):
	• Z punktu widzenia statystyki wielkość zbioru testowego decyduje o szerokości 95% przedziału ufności (CI) dla Twoich wyników (np. czułości/specyficzności).
	• Przy 100 próbkach testowych błąd standardowy dla skuteczności 90% wynosi \(\pm 6\%\) (95% CI: 84%–96%).
	• Przy 500 próbkach testowych błąd spada do \(\pm 2.6\%\) (95% CI: 87.4%–92.6%).
	• Dlatego zbiór testowy na poziomie 300–500 próbek na klasę daje już bardzo wąskie, publikowalne przedziały ufności.

Praktyczna tabela decyzyjna (Kiedy Ścieżka A, a kiedy Ścieżka B?)

Gdy uruchomisz funkcję inspect_data(), spójrz na liczbę unikalnych lncRNA po deduplikacji:

Liczba dostępnych lncRNA (po deduplikacji)	Rekomendacja statystyczna	Co robisz w prepare_data()?

# ==============================================================================
# KROK 1: FUNKCJA DO INSPEKCJI LICZEBNOŚCI PRZED PODZIAŁEM
# ==============================================================================
inspect_data <- function(cds_file,
                         nc_file,
                         lnc_file    = NULL,
                         ex_file     = NULL,
                         lnc_pattern = "lncRNA|lnc_rna|long_non_coding",
                         dedup_mode  = "exact_seq") { # "none", "exact_seq", "header_id"

  # Wczytanie plików
  cds <- readDNAStringSet(cds_file)
  nc  <- readDNAStringSet(nc_file)
  
  df_cds <- data.frame(old_name = names(cds), raw_group = "cds", seq_char = as.character(cds), stringsAsFactors = FALSE)
  df_nc  <- data.frame(old_name = names(nc),  raw_group = "nc",  seq_char = as.character(nc),  stringsAsFactors = FALSE)
  
  df_lnc <- if (!is.null(lnc_file)) {
    lnc <- readDNAStringSet(lnc_file)
    data.frame(old_name = names(lnc), raw_group = "lnc_ext", seq_char = as.character(lnc), stringsAsFactors = FALSE)
  } else NULL

  df_ex <- if (!is.null(ex_file)) {
    ex <- readDNAStringSet(ex_file)
    data.frame(old_name = names(ex), raw_group = "ex", seq_char = as.character(ex), stringsAsFactors = FALSE)
  } else NULL

  # Kolejność priorytetów przy deduplikacji: cds > lnc_ext > nc > ex
  df_all <- rbind(df_cds, df_lnc, df_nc, df_ex)
  raw_counts <- table(df_all$raw_group)

  # Opcjonalna deduplikacja
  if (dedup_mode != "none") {
    if (dedup_mode == "exact_seq") {
      dup_mask <- duplicated(df_all$seq_char)
    } else if (dedup_mode == "header_id") {
      clean_ids <- sub("\\s+.*$", "", df_all$old_name)
      dup_mask <- duplicated(clean_ids)
    } else {
      stop("Nieznany dedup_mode. Wybierz: 'none', 'exact_seq' lub 'header_id'.")
    }
    df_all <- df_all[!dup_mask, ]
  }

  # Identyfikacja kandydatów na lncRNA
  in_lnc_ext  <- df_all$raw_group == "lnc_ext"
  in_nc_match <- df_all$raw_group == "nc" & grepl(lnc_pattern, df_all$old_name, ignore.case = TRUE)
  is_lnc      <- in_lnc_ext | in_nc_match

  n_cds      <- sum(df_all$raw_group == "cds")
  n_nc_total <- sum(df_all$raw_group %in% c("nc", "lnc_ext"))
  n_lnc      <- sum(is_lnc)
  n_nc_other <- n_nc_total - n_lnc
  n_ex       <- sum(df_all$raw_group == "ex")

  # Raport w konsoli
  cat("\n==============================================================\n")
  cat(sprintf(" RAPORT INSPEKCJI DANYCH (dedup_mode = '%s')\n", dedup_mode))
  cat("==============================================================\n")
  cat("1. Liczebności SUROWE (przed deduplikacją):\n")
  print(raw_counts)
  cat("\n2. Liczebności PO DEDUPLIKACJI (unikalne do podziału):\n")
  cat(sprintf("   - cds (kodujące)          : %d\n", n_cds))
  cat(sprintf("   - nc (wszystkie niekod.)  : %d\n", n_nc_total))
  cat(sprintf("       * w tym wykryte lnc   : %d (wzorzec: '%s')\n", n_lnc, lnc_pattern))
  cat(sprintf("       * w tym nc_other      : %d\n", n_nc_other))
  cat(sprintf("   - ex (do predykcji)       : %d\n", n_ex))
  cat("--------------------------------------------------------------\n")
  cat("3. Symulacja dostępnych próbek w etapie ML (po podziale 50/50):\n")
  cat(sprintf("   - ŚCIEŻKA A (extract_lnc = TRUE)  -> ok. %d lnc (%d train / %d test)\n", 
              floor(n_lnc * 0.5), floor(n_lnc * 0.4), floor(n_lnc * 0.1)))
  cat(sprintf("   - ŚCIEŻKA B (extract_lnc = FALSE) -> ok. %d nc  (%d train / %d test)\n", 
              floor(n_nc_total * 0.5), floor(n_nc_total * 0.4), floor(n_nc_total * 0.1)))
  cat("==============================================================\n\n")

  invisible(list(n_cds = n_cds, n_nc_total = n_nc_total, n_lnc = n_lnc, n_nc_other = n_nc_other, n_ex = n_ex))
}


# ==============================================================================
# KROK 2: WŁAŚCIWA FUNKCJA DZIELĄCA (DATASET PREPARATION)
# ==============================================================================
prepare_data <- function(cds_file,
                         nc_file,
                         lnc_file      = NULL,
                         ex_file       = NULL,
                         prefix        = "Species",
                         extract_lnc   = TRUE,          # Ścieżka A (TRUE) vs Ścieżka B (FALSE)
                         lnc_pattern   = "lncRNA|lnc_rna|long_non_coding",
                         dedup_mode    = "exact_seq",   # "none", "exact_seq", "header_id"
                         seed          = 123,
                         stage_prop    = 0.5,
                         stage_method  = "exact",
                         tt_prop       = 0.8,
                         tt_method     = "exact",
                         max_n_stage   = Inf,           # np. 2500 (2000 train + 500 test) lub Inf
                         balance_train = TRUE,
                         ml_neg_mode   = "cds_only") {  # "cds_only" lub "cds_and_nc_other"

  set.seed(seed)

  # Wczytanie
  cds <- readDNAStringSet(cds_file)
  nc  <- readDNAStringSet(nc_file)
  
  df_cds <- data.frame(old_name = names(cds), raw_group = "cds", seq_char = as.character(cds), stringsAsFactors = FALSE)
  df_nc  <- data.frame(old_name = names(nc),  raw_group = "nc",  seq_char = as.character(nc),  stringsAsFactors = FALSE)
  
  df_lnc <- if (!is.null(lnc_file)) {
    lnc <- readDNAStringSet(lnc_file)
    data.frame(old_name = names(lnc), raw_group = "lnc_ext", seq_char = as.character(lnc), stringsAsFactors = FALSE)
  } else NULL

  df_ex <- if (!is.null(ex_file)) {
    ex <- readDNAStringSet(ex_file)
    data.frame(old_name = names(ex), raw_group = "ex", seq_char = as.character(ex), stringsAsFactors = FALSE)
  } else NULL

  df_all <- rbind(df_cds, df_lnc, df_nc, df_ex)

  # Deduplikacja
  if (dedup_mode != "none") {
    if (dedup_mode == "exact_seq") {
      dup_mask <- duplicated(df_all$seq_char)
    } else if (dedup_mode == "header_id") {
      clean_ids <- sub("\\s+.*$", "", df_all$old_name)
      dup_mask <- duplicated(clean_ids)
    } else {
      stop("Nieznany dedup_mode. Wybierz: 'none', 'exact_seq' lub 'header_id'.")
    }
    df_all <- df_all[!dup_mask, ]
  }

  # Przypisanie klas (Ścieżka A vs Ścieżka B)
  in_lnc_ext  <- df_all$raw_group == "lnc_ext"
  in_nc_match <- df_all$raw_group == "nc" & grepl(lnc_pattern, df_all$old_name, ignore.case = TRUE)
  is_lnc      <- in_lnc_ext | in_nc_match

  df_all$class <- df_all$raw_group
  if (extract_lnc) {
    df_all$class[is_lnc] <- "lnc"
    df_all$class[df_all$raw_group == "nc" & !is_lnc] <- "nc_other"
  } else {
    df_all$class[df_all$raw_group %in% c("nc", "lnc_ext")] <- "nc"
  }

  # Nadanie czystych ID
  df_all$ID <- ave(df_all$class, df_all$class, FUN = function(x) {
    paste(prefix, x, sprintf("%07d", seq_along(x)), sep = "_")
  })

  df_ref <- df_all[df_all$class != "ex", ]
  df_exp <- df_all[df_all$class == "ex", ]

  # Funkcja podziału
  split_vec <- function(n, labels, prop, method) {
    if (n == 0) return(character(0))
    if (method == "rep") {
      rep(labels, length.out = n)
    } else if (method == "sample") {
      sample(labels, size = n, replace = TRUE, prob = c(prop, 1 - prop))
    } else {
      n1 <- round(n * prop)
      sample(c(rep(labels, n1), rep(labels, n - n1)))
    }
  }

  # Podział na etapy (ml vs cp) oraz train vs test
  df_ref$stage <- ave(df_ref$class, df_ref$class, FUN = function(x) {
    split_vec(length(x), c("ml", "cp"), stage_prop, stage_method)
  })

  grp <- paste(df_ref$class, df_ref$stage, sep = "_")
  df_ref$tt_set <- ave(grp, grp, FUN = function(x) {
    split_vec(length(x), c("train", "test"), tt_prop, tt_method)
  })

  df_ref$cohort <- paste(df_ref$class, df_ref$stage, df_ref$tt_set, sep = "_")
  df_ref$keep   <- TRUE

  # Przypisanie ról (pos / neg)
  df_ref$role <- NA_character_
  if (extract_lnc) {
    df_ref$role[df_ref$stage == "cp" & df_ref$class %in% c("lnc", "nc_other")] <- "pos"
    df_ref$role[df_ref$stage == "cp" & df_ref$class == "cds"]                    <- "neg"
    df_ref$role[df_ref$stage == "ml" & df_ref$class == "lnc"]                    <- "pos"
    if (ml_neg_mode == "cds_only") {
      df_ref$role[df_ref$stage == "ml" & df_ref$class == "cds"]                  <- "neg"
      df_ref$keep[df_ref$stage == "ml" & df_ref$class == "nc_other"]             <- FALSE
    } else {
      df_ref$role[df_ref$stage == "ml" & df_ref$class %in% c("cds", "nc_other")] <- "neg"
    }
  } else {
    df_ref$role[df_ref$class == "nc"]  <- "pos"
    df_ref$role[df_ref$class == "cds"] <- "neg"
  }

  # Limit liczebności oraz balansowanie 1:1
  if (balance_train || is.finite(max_n_stage)) {
    for (st in c("cp", "ml")) {
      max_tr <- floor(max_n_stage * tt_prop)
      max_te <- floor(max_n_stage * (1 - tt_prop))

      for (tt in c("train", "test")) {
        lim <- if (tt == "train") max_tr else max_te
        idx_pos <- which(df_ref$stage == st & df_ref$tt_set == tt & df_ref$role == "pos" & df_ref$keep)
        idx_neg <- which(df_ref$stage == st & df_ref$tt_set == tt & df_ref$role == "neg" & df_ref$keep)

        if (tt == "train" && balance_train) {
          target_n <- min(length(idx_pos), length(idx_neg), lim)
        } else {
          target_n <- min(max(length(idx_pos), length(idx_neg)), lim)
        }

        if (length(idx_pos) > target_n) {
          df_ref$keep[idx_pos[sample.int(length(idx_pos), length(idx_pos) - target_n)]] <- FALSE
        }
        if (length(idx_neg) > target_n) {
          df_ref$keep[idx_neg[sample.int(length(idx_neg), length(idx_neg) - target_n)]] <- FALSE
        }
      }
    }
  }

  # Zbiór ex
  if (nrow(df_exp) > 0) {
    df_exp$stage  <- "inference"
    df_exp$tt_set <- "predict"
    df_exp$cohort <- "ex_inference"
    df_exp$keep   <- TRUE
    df_exp$role   <- "unknown"
    df_final <- rbind(df_ref, df_exp)
  } else {
    df_final <- df_ref
  }

  all_seqs <- DNAStringSet(df_final$seq_char)
  names(all_seqs) <- df_final$ID
  df_final$seq_char <- NULL

Używaj kodu z rozwagą.
return(list(seqs = all_seqs, legend = df_final))
}

Zgodnie z Twoją sugestią odchodzimy od jednej wielkiej funkcji-kombajnu. Zamiast tego masz 4 małe, wyspecjalizowane i przejrzyste funkcje (każda robi jedną konkretną rzecz), a do tego pełną możliwość podawania osobnych limitów oraz osobnych proporcji dla etapu cp i ml.

1. Metodologia podziału i podstawy statystyczne


Dlaczego dzielimy dane na dwa rozłączne bloki (cp i ml)?

W Twoim pipeline'ie wyniki z pierwszego etapu (cp – narzędzia oceny potencjału kodowania) stają się cechami wejściowymi dla drugiego etapu (ml – klasyfikator łączący wyniki cp z cechami transkryptu: długością, liczbą eksonów, ogonem polyA itp.).
• Gdybyś trenował cp i ml na tych samych transkryptach, narzędzia z cp miałyby na nich sztucznie zawyżoną skuteczność (bo już je widziały w treningu), co zafałszowałoby wagi w modelu ml (data leakage).
• Dlatego referencję (cds i nc/lnc) dzielimy na dwie całkowicie rozłączne pule: Pulę CP oraz Pulę ML.
• Zbiór eksperymentalny ze StringTie (ex) musi być uprzednio oczyszczony z sekwencji identycznych z cds oraz nc, a następnie w 100% służy wyłącznie do predykcji (nigdy nie wchodzi do treningu ani testu).

Podwójna ścieżka dla lncRNA (Ścieżka A vs Ścieżka B)

• Ścieżka A (extract_lnc = TRUE – organizmy modelowe i dobrze zaadnotowane): Z pliku nc wyodrębniamy podklasę lnc (po wzorcu w nagłówku lub z osobnego pliku), a resztę oznaczamy jako nc_other. W etapie cp trenujemy i testujemy na pełnym nc (lnc + nc_other vs cds), co zachowuje naturalny rozkład. W etapie ml klasą pozytywną jest już wyłącznie lnc (przeciwko cds lub cds + nc_other).
• Ścieżka B (extract_lnc = FALSE – ubogie organizmy niemodelowe): Gdy lncRNA jest w bazie za mało, nie rozbijamy nc na podklasy. Zarówno w cp, jak i w ml klasą pozytywną jest całe nc przeciwko cds.

Teoria statystyki a dobór liczebności próbek

1. Reguła EPV (Events Per Variable – reguła Harrella/Peduzziego): Na każdą cechę wejściową w modelu powinno przypadać minimum 15–20 obserwacji z klasy mniejszościowej w zbiorze treningowym (Train). Jeśli w etapie ml masz 15 cech, potrzebujesz minimum \(15 \times 20 = 300\) lncRNA w zbiorze ml_train (czyli ok. 375 lncRNA w całym bloku ml, a ~750 lncRNA łącznie w bazie przed podziałem na cp i ml). Poniżej tej granicy rośnie ryzyko przeuczenia (overfitting).
2. Wypłaszczenie krzywej uczenia (Power Law Plateau): Algorytmy tabelaryczne (XGBoost, Random Forest, LightGBM) operujące na kilkunastu/kilkudziesięciu cechach osiągają wysycenie przy ok. 1 500 – 2 500 próbkach na klasę w zbiorze treningowym. Powyżej tej wartości przyrost AUC/F1 jest marginalny (<0.2%), a rośnie jedynie czas obliczeń.
3. Precyzja metryk w zbiorze Testowym (95% przedziały ufności): Zbiór testowy rzędu 300–500 próbek na klasę zapewnia wąski błąd standardowy estymacji (ok. \(\pm 2.5\%\) dla skuteczności ~90%), co jest w pełni akceptowalne w publikacjach naukowych.

# ==============================================================================
# FUNKCJA 1: Wczytanie plików FASTA, tagowanie lncRNA i opcjonalna deduplikacja
# ==============================================================================
load_and_dedup <- function(cds_file,
                           nc_file,
                           lnc_file    = NULL,
                           ex_file     = NULL,
                           extract_lnc = TRUE,
                           lnc_pattern = "lncRNA|lnc_rna|long_non_coding",
                           dedup_mode  = "exact_seq") { # "none", "exact_seq", "header_id"

  read_to_df <- function(file, group_name) {
    if (is.null(file)) return(NULL)
    s <- readDNAStringSet(file)
    data.frame(old_name = names(s), raw_group = group_name, seq_char = as.character(s), stringsAsFactors = FALSE)
  }

  # Kolejność priorytetów przy deduplikacji: cds > lnc_ext > nc > ex
  df <- rbind(
    read_to_df(cds_file, "cds"),
    read_to_df(lnc_file, "lnc_ext"),
    read_to_df(nc_file,  "nc"),
    read_to_df(ex_file,  "ex")
  )

  # Opcjonalna deduplikacja
  if (dedup_mode == "exact_seq") {
    df <- df[!duplicated(df$seq_char), ]
  } else if (dedup_mode == "header_id") {
    clean_ids <- sub("\\s+.*$", "", df$old_name)
    df <- df[!duplicated(clean_ids), ]
  } else if (dedup_mode != "none") {
    stop("Nieznany dedup_mode. Wybierz: 'none', 'exact_seq' lub 'header_id'.")
  }

  # Przypisanie klas: Ścieżka A (extract_lnc = TRUE) vs Ścieżka B (FALSE)
  is_lnc <- (df$raw_group == "lnc_ext") |
            (df$raw_group == "nc" & grepl(lnc_pattern, df$old_name, ignore.case = TRUE))

  df$class <- df$raw_group
  if (extract_lnc) {
    df$class[is_lnc] <- "lnc"
    df$class[df$raw_group == "nc" & !is_lnc] <- "nc_other"
  } else {
    df$class[df$raw_group %in% c("nc", "lnc_ext")] <- "nc"
  }

  return(df)
}

# ==============================================================================
# FUNKCJA 3: Podział na etapy (cp / ml), zbiory (train / test) oraz limity
# ==============================================================================
split_datasets <- function(df,
                           prefix        = "Species",
                           seed          = 123,
                           cp_stage_prop = 0.5,        # Jaka część referencji trafia do etapu 'cp' (reszta do 'ml')
                           cp_tt_prop    = 0.8,        # Proporcja train/test w etapie 'cp'
                           ml_tt_prop    = 0.8,        # Proporcja train/test w etapie 'ml'
                           max_n_cp      = Inf,        # Limit próbek na rolę (pos/neg) w etapie 'cp' (train + test)
                           max_n_ml      = Inf,        # Limit próbek na rolę (pos/neg) w etapie 'ml' (train + test)
                           balance_train = TRUE,       # Wyrównanie 1:1 w zbiorach train
                           ml_neg_mode   = "cds_only") # W Ścieżce A: "cds_only" lub "cds_and_nc_other"
{
  set.seed(seed)

  # Nadanie unikalnych ID
  df$ID <- ave(df$class, df$class, FUN = function(x) {
    paste(prefix, x, sprintf("%07d", seq_along(x)), sep = "_")
  })

  df_ref <- df[df$class != "ex", ]
  df_exp <- df[df$class == "ex", ]

  split_exact <- function(n, labels, prop) {
    if (n == 0) return(character(0))
    n1 <- round(n * prop)
    sample(c(rep(labels[1], n1), rep(labels[2], n - n1)))
  }

  # 1. Podział na etapy: cp vs ml (stratyfikowany po 'class')
  df_ref$stage <- ave(df_ref$class, df_ref$class, FUN = function(x) {
    split_exact(length(x), c("cp", "ml"), cp_stage_prop)
  })

  # 2. Podział train vs test z osobnymi proporcjami dla cp i ml
  df_ref$tt_set <- NA_character_
  for (st in c("cp", "ml")) {
    prop <- if (st == "cp") cp_tt_prop else ml_tt_prop
    idx  <- which(df_ref$stage == st)
    df_ref$tt_set[idx] <- ave(df_ref$class[idx], df_ref$class[idx], FUN = function(x) {
      split_exact(length(x), c("train", "test"), prop)
    })
  }

  df_ref$cohort <- paste(df_ref$class, df_ref$stage, df_ref$tt_set, sep = "_")
  df_ref$keep   <- TRUE

  # 3. Przypisanie ról (pos / neg)
  df_ref$role <- NA_character_
  has_lnc <- "lnc" %in% df_ref$class

  if (has_lnc) {
    # Ścieżka A
    df_ref$role[df_ref$stage == "cp" & df_ref$class %in% c("lnc", "nc_other")] <- "pos"
    df_ref$role[df_ref$stage == "cp" & df_ref$class == "cds"]                    <- "neg"
    df_ref$role[df_ref$stage == "ml" & df_ref$class == "lnc"]                    <- "pos"
    if (ml_neg_mode == "cds_only") {
      df_ref$role[df_ref$stage == "ml" & df_ref$class == "cds"]                  <- "neg"
      df_ref$keep[df_ref$stage == "ml" & df_ref$class == "nc_other"]             <- FALSE
    } else {
      df_ref$role[df_ref$stage == "ml" & df_ref$class %in% c("cds", "nc_other")] <- "neg"
    }
  } else {
    # Ścieżka B
    df_ref$role[df_ref$class == "nc"]  <- "pos"
    df_ref$role[df_ref$class == "cds"] <- "neg"
  }

  # 4. Osobne limity (max_n_cp, max_n_ml) i balansowanie 1:1
  for (st in c("cp", "ml")) {
    lim_total <- if (st == "cp") max_n_cp else max_n_ml
    tt_p      <- if (st == "cp") cp_tt_prop else ml_tt_prop

    for (tt in c("train", "test")) {
      lim <- if (tt == "train") floor(lim_total * tt_p) else floor(lim_total * (1 - tt_p))
      idx_pos <- which(df_ref$stage == st & df_ref$tt_set == tt & df_ref$role == "pos" & df_ref$keep)
      idx_neg <- which(df_ref$stage == st & df_ref$tt_set == tt & df_ref$role == "neg" & df_ref$keep)

      if (tt == "train" && balance_train) {
        target_n <- min(length(idx_pos), length(idx_neg), lim)
      } else {
        target_n <- min(max(length(idx_pos), length(idx_neg)), lim)
      }

      if (length(idx_pos) > target_n) {
        df_ref$keep[idx_pos[sample.int(length(idx_pos), length(idx_pos) - target_n)]] <- FALSE
      }
      if (length(idx_neg) > target_n) {
        df_ref$keep[idx_neg[sample.int(length(idx_neg), length(idx_neg) - target_n)]] <- FALSE
      }
    }
  }

  # 5. Dołączenie zbioru ex (jeśli istnieje)
  if (nrow(df_exp) > 0) {
    df_exp$stage  <- "inference"
    df_exp$tt_set <- "predict"
    df_exp$cohort <- "ex_inference"
    df_exp$keep   <- TRUE
    df_exp$role   <- "unknown"
    df_final <- rbind(df_ref, df_exp)
  } else {
    df_final <- df_ref
  }

  all_seqs <- DNAStringSet(df_final$seq_char)
  names(all_seqs) <- df_final$ID
  df_final$seq_char <- NULL

  return(list(seqs = all_seqs, legend = df_final))
}


# ==============================================================================
# FUNKCJA 4: Pomocnicze wyciąganie gotowych podzbiorów sekwencji (FASTA)
# ==============================================================================
extract_subset <- function(wynik, stage_name, tt_name = NULL, role_name = NULL, only_kept = TRUE) {
  df <- wynik$legend
  mask <- df$stage == stage_name
  if (!is.null(tt_name))   mask <- mask & (df$tt_set == tt_name)
  if (!is.null(role_name)) mask <- mask & (df$role == role_name)
  if (only_kept)           mask <- mask & df$keep
  
  return(wynik$seqs[df$ID[mask]])
}
